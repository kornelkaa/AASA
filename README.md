An end-to-end **Neuro-Symbolic Autonomous Scene Understanding Platform** built for real-time 3D sensor fusion, physical hazard estimation, multi-frame velocity tracking, and LLM-driven structured safety decision-making.

This project bridges traditional **Computer Vision (PyTorch & YOLOv8)** with **3D Lidar Point Cloud Projection**, a custom **PyTorch Multi-Layer Perceptron (MLP)** hazard evaluator, **Temporal Motion Tracking**, and **Agentic AI Reasoning (Groq / Qwen / Gemini)** into an interactive web dashboard and Dockerized application.
